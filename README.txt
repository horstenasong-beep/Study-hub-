STUDY HUB — STARTER WEBSITE

Files:
- index.html: page structure
- styles.css: responsive styling
- app.js: resource catalogue, search/filter, detail popups and quick quiz

HOW TO PREVIEW
Open index.html in a browser. For online publishing, upload the contents of this folder to a static hosting service such as Netlify or GitHub Pages.

IMPORTANT CONTENT NOTE
This starter contains sample catalogue entries and original short descriptions, not full commercial textbooks. Do not upload copyrighted textbooks unless you have permission. The full library should use original materials, openly licensed resources, public-domain works, or files you are authorised to distribute.

WHAT IS STILL NEEDED FOR A COMPLETE ONLINE PLATFORM
1. Confirm the curriculum and exact class naming.
2. Collect or create authorised textbook/workbook PDFs by class and subject.
3. Add cloud file storage and a database for resource records.
4. Add secure student/admin accounts and an admin upload area.
5. Add hosted quizzes, saved progress and accessibility checks.
6. Test on phones and deploy to a public domain.

This is a front-end starter, not yet a full account-based platform. Search/filter and the demo quiz work in the browser; cloud storage, logins and uploaded content are not connected yet.
